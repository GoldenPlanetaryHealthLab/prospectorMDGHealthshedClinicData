Tip Procedure: Record Coordinate Policy And Declare Helpers

Reviewed policy: preserve legacy missing coordinates for UNICEF. Both unicef and unicef2 retain missing coordinates in S7 even when S6 selected a valid UNICEF candidate. The policy is a tracked target, and the coordinate status explicitly identifies these rows. Other labels ending in 2 use their stored source pair; the original label remains in gps_source_raw.

Centroids use the same sf::st_centroid() operation and input CRS as the legacy script. Only the selected, nonempty geometries need calculation. No new projection, geodesic algorithm, or point-on-surface rule is introduced. Empty geometries yield missing coordinates. The spatial runtime from page 23 remains a dependency of location extraction and centroid calculation.

s7_clinic_centroid_xy_fn <- function(geometry) {
  result <- matrix(NA_real_, nrow = length(geometry), ncol = 2L,
                   dimnames = list(NULL, c("x", "y")))
  present <- which(!sf::st_is_empty(geometry))
  if (length(present)) {
    result[present, ] <- sf::st_coordinates(sf::st_centroid(geometry[present]))[, c("X", "Y"), drop = FALSE]
  }
  result
}
s7_clinic_selected_coordinates_fn <- function(locations, policy) {
  stopifnot(identical(policy$unicef, "legacy_missing"))
  label <- sub("2$", "", as.character(locations$which_use))
  result <- tibble::tibble(fs_uid = locations$fs_uid,
    gps_source_raw = as.character(locations$which_use), which_use = label,
    clinic_x = rep(NA_real_, nrow(locations)), clinic_y = rep(NA_real_, nrow(locations)))
  for (source in c("who", "mdss", "sect", "gps")) {
    selected <- which(label == source)
    if (length(selected)) {
      result$clinic_x[selected] <- as.numeric(locations[[paste0(source, "_x")]][selected])
      result$clinic_y[selected] <- as.numeric(locations[[paste0(source, "_y")]][selected])
    }
  }
  selected <- which(label == "fkt_centroid")
  if (length(selected)) {
    xy <- s7_clinic_centroid_xy_fn(locations$fkt_geometry[selected])
    result$clinic_x[selected] <- xy[, "x"]
    result$clinic_y[selected] <- xy[, "y"]
  }
  result
}
s7_clinic_reporting_long_fn <- function(tracker) {
  tracker %>% tidyr::pivot_longer(!clinic_ID, names_to = "year_month", values_to = "fname") %>%
    tidyr::separate_wider_position(year_month, widths = c(1, year = 4, 2, month = 2), cols_remove = FALSE) %>%
    mutate(across(c(year, month), as.numeric))
}

Tip Procedure: Summarize Reporting And Apply Attribute Precedence

The clinic-level population includes only clinics with at least one retained report. n_month counts distinct reported calendar labels; first_report and last_report use those zero-padded labels, not a duration calculation.

Sectorization attributes win when present. The historical fallback uses all records tied at cAnnee + cPeriode / 13’s maximum, then the legacy distinct attribute projection. Ownership is a legacy heuristic: a nonmissing sectorization type other than FSP implies public, with ID_checked as fallback.
