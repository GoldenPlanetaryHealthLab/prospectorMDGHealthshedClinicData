23  Compare and Select Clinic Locations

Implement legacy stage 6 with candidate and selection evidence

This page implements 6_locate_clinics.R at pinned revision 31e0769683e133e136b09ac0c6608c5a12657a9a. Each row is a clinic-location candidate, not necessarily a unique clinic. Matching ties and full-join-only clinics remain visible. Five reported coordinate sources, a matched FKT, and a healthshed supply the evidence for the fixed source-selection order. A selected centroid label denotes an inferred location, not a measured point.

Tip Procedure: Declare Source, Point, And Intersection Helpers

unique_nonNA() follows the legacy rule: remove missing values only when nonmissing values exist, retaining multiple distinct values as ambiguity. The unused legacy mode() has no consumer and is omitted.

Point conversion retains all original coordinate columns. Numeric coercion has the legacy missing-coordinate behavior (na.fail = FALSE); malformed text raises a coercion warning; the original text remains in the raw source targets. No coordinate swap, range clipping, or inferred sign correction is introduced.

The fields ending in Contains use st_intersects(), including boundary intersections. The sparse result is checked at matching row indices, giving the same diagonal as the legacy dense matrix without allocating that matrix. An empty point produces NA, while a nonempty point against an empty polygon produces zero. The input CRS and global s2 setting remain unchanged.

s6_clinic_location_unique_nonNA_fn <- function(x) {
  x <- unique(x)
  if (any(is.na(x)) && !all(is.na(x))) x <- stats::na.omit(x)
  x
}
s6_clinic_location_read_fn <- function(archive, member) {
  s3_dictionary_archive_read_fn(archive, member, function(path) {
    read.csv(path, colClasses = "character", fileEncoding = "UTF-8",
             stringsAsFactors = FALSE)
  })
}
s6_clinic_location_points_fn <- function(x) {
  x <- as.data.frame(x)
  for (source in c("sect", "mdss", "who", "unicef", "gps")) {
    columns <- paste0(source, c("_x", "_y"))
    xy <- as.data.frame(lapply(x[columns], as.numeric))
    x[[paste0(source, "_ll")]] <- sf::st_geometry(sf::st_as_sf(
      xy, coords = columns, remove = FALSE, na.fail = FALSE, crs = 4326))
  }
  sf::st_as_sf(x, sf_column_name = "sect_ll")
}
s6_clinic_location_intersects_fn <- function(points, polygons) {
  stopifnot(length(points) == length(polygons))
  hits <- sf::st_intersects(points, polygons)
  result <- as.numeric(vapply(seq_along(hits), function(i) i %in% hits[[i]], logical(1)))
  result[sf::st_is_empty(points)] <- NA_real_
  result
}
s6_clinic_location_select_fn <- function(x) {
  mutate(x, which_use = case_when(
    who_ll_fktContains == 1 ~ "who",
    sect_ll_fktContains == 1 ~ "sect",
    unicef_ll_fktContains == 1 ~ "unicef",
    mdss_ll_fktContains == 1 ~ "mdss",
    gps_ll_shedContains == 1 ~ "gps",
    who_ll_shedContains == 1 ~ "who2",
    sect_ll_shedContains == 1 ~ "sect2",
    unicef_ll_shedContains == 1 ~ "unicef2",
    mdss_ll_shedContains == 1 ~ "mdss2",
    gps_ll_shedContains == 1 ~ "gps2",
    !sf::st_is_empty(fkt_geometry) ~ "fkt_centroid",
    !sf::st_is_empty(shed_geometry) ~ "shed_centroid",
    TRUE ~ "none"))
}

Tip Procedure: Identify A Unique Matching FKT

Keep the combined minimum-name-distance, <= 0.12 or name-containment, and minimum-geographic-distance condition. A single FKT qualifies independently of that condition. Distances retain the legacy comma and kilometer-string conversion. sum() and name min() retain missing values; ties or missing evidence may prevent a unique match rather than force a winner. The full ranked table remains available, including rejected candidates.

Name containment uses stringi’s ICU regex matcher, the same regex engine used by stringr, with missing patterns propagated as NA. A missing clinic name becomes the pattern in the reverse containment test; stringr rejects that pattern before matching. Retaining NA preserves unknown evidence and the separate single-FKT rule without dropping assignment rows or filling missing names with empty strings.

s6_clinic_location_fkt_candidates_fn <- function(sect) {
  sect %>% filter(fkt_name != "" & !is.na(fkt_name)) %>%
    mutate(name_noPre = gsub("CSB1 |CSB2 |HP_|HP |FSP_|FSP_ |FSP ", "", fs_name),
      fkt_fs_stringdist = stringdist::stringdist(tolower(name_noPre), tolower(fkt_name), method = "cosine"),
      name_contain = stringi::stri_detect_regex(tolower(name_noPre), tolower(fkt_name)) |
        stringi::stri_detect_regex(tolower(fkt_name), tolower(name_noPre)),
      dist = gsub(",", ".", distance_csb_fkt) %>%
        gsub("Km|Km| km|km", "", .) %>% na_if("") %>% as.numeric()) %>%
    group_by(fs_uid) %>%
    mutate(n_fkt = n(),
      match_name_dist = (fkt_fs_stringdist == min(fkt_fs_stringdist) &
        (fkt_fs_stringdist <= 0.12 | name_contain) & dist == min(dist, na.rm = TRUE)) | n_fkt == 1,
      n_match = sum(match_name_dist)) %>% ungroup()
}
