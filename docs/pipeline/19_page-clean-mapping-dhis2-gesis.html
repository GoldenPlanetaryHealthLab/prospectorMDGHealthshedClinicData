16  Clean the DHIS2–GESIS Mapping

Preserve the reviewed legacy workflow while modernizing it in stages

This page translates the reviewed DHIS2–GESIS mapping-cleaning workflow into successive targets. The stage boundaries separate source reads, reviewed corrections, validation queries, and persistence so each decision remains auditable while the execution becomes reproducible.

WarningPreserve reviewed decisions while modernizing

The transformations below preserve the reviewed mapping decisions from the legacy workflow. Each assigned object is a pipeline target. Diagnostic chunks in the final check are deliberately unassigned: they inspect completed targets without adding check-only objects to the graph. The authoring render does not execute them.

Important Prerequisite: Retain The Reviewed Source Evidence

The original mapping CSV and the four manually reviewed workbooks or CSVs must remain available with their provenance intact. Before optimizing a stage, record its input schema, expected row-count change, join cardinality, and the review decision represented by each correction.

Tip Procedure: Stages 2–3 — Correct GESIS Codes And Fill The Known UID

This stage loads the reviewed corrections, checks UID consistency for both the old and corrected codes, applies the corrected GESIS code, and fills the known UID for GESIS code 630151027.

#| format: file
# 2) bits out of range ------
# Some clinic GESIS codes have the type or public/private bits out of the expected range, 
# sometimes, those GESIS codes should be corrected 
s1_gesis_code_corrections_raw_xlsx <- str_subset(s0_pipeline_inputs_raw_chr, "CSB1 CSB2 PUBLIC PRIVATE.xlsx")
s1_gesis_code_corrections_df <- read_xlsx(s1_gesis_code_corrections_raw_xlsx) |>
  filter(!is.na(`NEW CODE`) & `NEW CODE` != "NEW CODE") %>% 
  setNames(c("old_code", "correct_code", "uid", "name", "status", "note")) %>% 
  unique()
# make the adjustment to the mapping file
s1_gesis_xwalk_corrected_df <- s1_gesis_xwalk_filtered_df %>%
  left_join(s1_gesis_code_corrections_df %>% select(code_fs = old_code, correct_code),
            by = c("code_fs")) %>% 
  mutate(code_fs = ifelse(is.na(correct_code), code_fs, correct_code)) %>% 
  select(-correct_code) %>%
  #manually fill the UID from other years for 630151027
  mutate(fs_uid = ifelse(code_fs == "630151027" & grepl("Ankilivalo", FS), 
                         "ZX5EkF6eC0x", 
                         fs_uid))
Tip Procedure: Stage 4 — Fill Missing UIDs From The Reviewed Workbook

This stage imports reviewed UID fills and applies them by GESIS clinic code.

#| format: file
# 4) fill in missing UIDs for GESIS-years in mapping ----
# for GESIS-years for public clinics in the mapping file
# reporting data in 2018/2019 using this file for those 4 clinics 
s1_gesis_uid_fills_raw_xlsx <- str_subset(s0_pipeline_inputs_raw_chr, "gesis_missing_uid_in_mapping.xlsx")
s1_gesis_uid_fills_df <- read_xlsx(s1_gesis_uid_fills_raw_xlsx) %>%

Join the reviewed fills onto the corrected mapping; leave unrelated UIDs unchanged.

s1_gesis_xwalk_uid_filled_df <- s1_gesis_xwalk_corrected_df %>%

            by = "code_fs") %>%

# this clinic was not captured in our 21 GESIS - UIDs with concerning name changes

Tip Procedure: Stage 5 — Reconcile UID-Years With Multiple GESIS Codes

This stage classifies reviewer notes, retains the original internal diagnostic as an executable check, evaluates external GESIS–UID consequences, and applies deletions and renames.

#| format: file
# 5) UID-years with multiple GESIS codes ---- 
s1_gesis_multiple_codes_raw_csv <- str_subset(
  s0_pipeline_inputs_raw_chr,
  "VERIFIER_fs_uid_year_with_multiple_gesis.csv"
)
s1_gesis_multiple_codes_reviewed_df <- read_delim(s1_gesis_multiple_codes_raw_csv, delim=";") %>%
  mutate(change = case_when(grepl("the clinic was moved to the district of mandoto", note) ~ "keep", 
                            note %in% c("Same clinic", "OK", "ok") ~ "keep", 
                            grepl("^rename", note) ~ "rename", 
                            grepl("delete|Delete", note) ~ "delete",
                            TRUE ~ as.character(NA)), 
         code_fs = as.character(code_fs)) 
# started with 36 UID-years with multiple GESIS 
# there are 2 deletions, 16 renames, and 18 cases where its just two codes for the same clinic
# --> 18 UID-years with multiple GESIS at the end
# make the change 
s1_gesis_xwalk_multiple_codes_reconciled_df <- s1_gesis_xwalk_uid_filled_df %>%
  # the UIDs got dropped when we rename, which only matters in one case 
  # whe the row needs to be deleted, so separately add in the delete cases vs rest
  left_join(s1_gesis_multiple_codes_reviewed_df %>%
              filter(change == "delete") %>% 
              select(cAnnee, code_fs, fs_uid, change),
            by = c("cAnnee", "code_fs", "fs_uid")) %>%
  filter(change != "delete" | is.na(change)) %>% 
  select(-change) %>% 
  left_join(s1_gesis_multiple_codes_reviewed_df %>%
              filter(change != "delete") %>% 
              select(cAnnee, code_fs, change,
                     fs_uid_correct = UID,
                     fs_name_correct = `NAME CLINICS`),
            by = c("cAnnee", "code_fs")) %>%
  mutate(fs_uid = case_when(change == "rename" & fs_uid_correct == "No UID" ~ "",
                            change == "rename" ~ fs_uid_correct,
                            TRUE ~ fs_uid),
         FS = case_when(change == "rename" & fs_name_correct != "" ~ fs_name_correct, 
                        TRUE ~ FS)) %>%
  select(-(change:fs_name_correct)) %>%
  verify(nrow(.) == 34810)
# deletes 2 rows, so now down to 34810

Tip Procedure: Stage 7b — Replace The Disputed New-2015 Match

Replace the reviewed GESIS/UID pairing for new-2015 with the corresponding old-2015 clinic record. Keep the source row as the evidence for its attributes.

s1_gesis_xwalk_manual_2015_corrected_df <- s1_gesis_xwalk_manual_codes_corrected_df %>%

Tip Procedure: Stage 7c — Replace The Historical Match

Warning Check: Verify Reviewed Mapping Outcomes

Run these queries after the mapping targets complete, in an authorized data session. They inspect the produced tables and compare them with reviewed expectations. An authoring render does not run these queries.

First confirm that the corrected mapping agrees with the reviewed replacement UIDs. The mismatch table must be empty.

#| eval: true
tar_read(s1_gesis_xwalk_corrected_df) %>%

    by = "code_fs"

  filter(!is.na(reviewed_uid), reviewed_uid != fs_uid) %>%
