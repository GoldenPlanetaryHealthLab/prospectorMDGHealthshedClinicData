18  Construct the Diagnosis Dictionary

Reconcile measurement definitions across Waves 1, 2, 3A, and 3B

This page implements 3_construct_dictionary.R as successive targets. It preserves the reviewed cross-wave mappings, supplemental diagnoses, wording corrections, and 40 output-file groups. Wave 3 measurements stay in Parquet: this stage needs their ordered column schema, not their rows.

Translations come from the archived source translations and the bilingual data/clean/diagnosis_dictionary_translated.csv snapshot in the staged ZIP. That snapshot supplies language lookups only; its variable IDs and mapping expressions do not replace the newly constructed dictionary. No translation service is called.

Page 18 must have produced s0_clinic_RMA_W3_clean_parquet, and page 20 must have selected s2_clinic_months_raw_zip. In an authorized R session, confirm that these tracked files exist. This check reads target metadata and paths, not the measurement tables.

s3_dictionary_archive_member_fn <- function(archive, suffix) {
  members <- utils::unzip(archive, list = TRUE)$Name
  hits <- members[endsWith(members, paste0("/", suffix)) &
                    !grepl("(^|/)__MACOSX/", members)]
  if (length(hits) != 1L) stop("Expected one archive member for: ", suffix)
  unname(hits)
}
s3_dictionary_archive_read_fn <- function(archive, member, reader) {
  stopifnot(length(member) == 1L, !grepl("^/|(^|/)\\.\\.(/|$)", member))
  extraction_dir <- tempfile("dictionary-input-")
  dir.create(extraction_dir)
  on.exit(unlink(extraction_dir, recursive = TRUE), add = TRUE)
  path <- utils::unzip(archive, files = member, exdir = extraction_dir)
  stopifnot(length(path) == 1L, file.exists(path))
  reader(path)
}

s3_dictionary_read_csv_fn <- function(archive, member) {
  s3_dictionary_archive_read_fn(archive, member, function(path) {
    read.csv(path, fileEncoding = "UTF-8", stringsAsFactors = FALSE)
  })
}

Apply the legacy wording substitutions sequentially. Unequal non-scalar pattern/replacement vectors fail explicitly instead of calling the legacy undefined error() function.

s3_diagnosis_multiple_gsub_fn <- function(patterns, replacements, x) {
  if (length(patterns) != length(replacements) &&
      length(patterns) != 1L && length(replacements) != 1L) {
    stop("Pattern and replacement must have equal length or be scalar.")
  }
  count <- max(length(patterns), length(replacements))
  patterns <- rep_len(patterns, count)
  replacements <- rep_len(replacements, count)
  for (i in seq_len(count)) x <- gsub(patterns[[i]], replacements[[i]], x)
  x
}

Tip Procedure: Aggregate Comparable Variables Across Waves

The shared reducer retains the legacy missing-component rule: if one component is unmatched, the aggregate for that other wave is missing. Repeated source expressions are cleared before retaining the first complete expression combination. These rules affect comparability and are not replaced by a generic sum or coalesce.

Select local column names with all_of()/pick() when the helper runs. This preserves grouped column lookup while avoiding premature unquotation when tar_tangle() declares the function target.

s3_diagnosis_aggregate_to_wave_fn <- function(df, target_wave,
                                     all_waves = paste0("wave", c(1:2, "3A", "3B"))) {
  other_waves = setdiff(all_waves, target_wave)
  target_col = paste0(target_wave, "_colname")
  target_desc = paste0(target_wave, "_description")
  other_col = paste0(other_waves, "_colname")
  filter(df, if_any(all_of(target_col), ~ !is.na(.x))) %>%
    summarise(description = unique(pick(all_of(target_desc))[[1L]]),
              across(all_of(other_col),
                     ~if(any(is.na(.x))){NA}else{paste(unique(.x), collapse = " + ")}),
              .by = all_of(target_col)) %>%
    mutate(wave1_colname = ifelse(n() == 1, wave1_colname, NA),
           .by = c(wave1_colname)) %>%
    mutate(wave2_colname = ifelse(n() == 1, wave2_colname, NA),
           .by = c(wave2_colname)) %>%
    mutate(wave3A_colname = ifelse(n() == 1, wave3A_colname, NA),
           .by = c(wave3A_colname)) %>%
    mutate(wave3B_colname = ifelse(n() == 1, wave3B_colname, NA),
           .by = c(wave3B_colname)) %>%
    return
}

s3_diagnosis_translation_lookup_fn <- function(data, french, english) {
  pairs <- tibble(french = data[[french]], english = data[[english]]) |>
    filter(!is.na(french), french != "", !is.na(english), english != "") |>
    distinct()
  if (anyDuplicated(pairs$french)) stop("Conflicting archived translations.")
  pairs
}

Tip Procedure: Declare Validation And Artifact Inspection Helpers

Validate the source-expression contract without evaluating expressions as R code. Report reused complete expressions, repeated summands, and terms absent from the corresponding source schema. Missing expressions remain allowed; they indicate that a comparable definition is unavailable in that wave.

s3_diagnosis_validate_fn <- function(dictionary, wave3_schema, wave12_dictionary) {
  empty <- tibble(var = character(), wave = character(), issue = character(),
                  expression = character())
  issues <- list(empty)
  for (wave in c("wave1", "wave2", "wave3A", "wave3B")) {
    expressions <- dictionary[[paste0(wave, "_colname")]]
    columns <- if (wave %in% c("wave1", "wave2")) {
      wave12_dictionary$Column.Name
    } else wave3_schema$w3_colname
    reused <- duplicated(expressions) | duplicated(expressions, fromLast = TRUE)
    for (i in which(!is.na(expressions))) {
      terms <- strsplit(expressions[[i]], " + ", fixed = TRUE)[[1]]
      problems <- c(if (reused[[i]]) "reused_expression",
                    if (anyDuplicated(terms)) "repeated_summand",
                    if (any(!terms %in% columns)) "unknown_source_column")
      if (length(problems)) issues[[length(issues) + 1L]] <- tibble(
        var = dictionary$var[[i]], wave = wave,
        issue = problems, expression = expressions[[i]]
      )
    }
  }
  bind_rows(issues)
}

The artifact inspector asks DuckDB for a scalar count and reads the file size from filesystem metadata. It never collects the dictionary rows, or the upstream Wave 3 measurement table.

s3_diagnosis_parquet_stats_fn <- function(path) {
  stopifnot(length(path) == 1L, file.exists(path))
  relation <- read_parquet_duckdb(path, prudence = "stingy")
  counts <- relation |> summarise(rows = n()) |> collect()
  tibble(file = basename(path), bytes = unname(file.info(path)$size),
         rows = counts$rows, columns = length(names(relation)))
}
